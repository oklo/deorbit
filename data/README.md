# External input data (provenance)

This directory holds **external, third-party input data** required to reproduce parts
of the project. The large binaries are **not committed** (gitignored); only this README,
`fetch.sh`, and `checksums.sha256` are tracked. Fetch the data with:

```bash
bash data/fetch.sh                      # downloads the JPL ephemerides (no login)
shasum -a 256 -c data/checksums.sha256  # verify everything present (after the DEM step too)
```

These are *inputs* (fetched from authoritative sources). This project's own simulation
**outputs** (snapshots, figures) are not stored here — they are regenerated by running the codes.

## `ephemerides/` — JPL Solar System ephemerides (used by `deorbit.highfidelity`)
ASSIST integrates the geocentric test particle in the DE440 force field; `hifi.py` loads:

| file | bytes | source (public, no login) |
|---|---|---|
| `linux_p1550p2650.440` | 102 MB | JPL DE440 planetary ephemeris — `https://ssd.jpl.nasa.gov/ftp/eph/planets/Linux/de440/linux_p1550p2650.440` |
| `sb441-n16.bsp` | 645 MB | JPL/ASSIST small-body ephemeris (16 asteroids) — `https://ssd.jpl.nasa.gov/ftp/eph/small_bodies/asteroids_de441/sb441-n16.bsp` |

`hifi.py` resolves this directory via `$DEORBIT_EPHEM_DIR`, else `data/ephemerides/`, else the
legacy `highfidelity/data/`.

## `dem/` — SRTM terrain tiles (used by `hydrocodes/sph/make_cayambe_ic.py`)
SRTMGL1 (1-arcsec, ~30 m) void-filled tiles covering Cayambe (~0°N, 78°W); each `.hgt`
is 3601×3601 big-endian int16 metres.

| file | source |
|---|---|
| `N00W078.hgt` (summit), `N00W079.hgt` (windward) | NASA SRTMGL1 v003, via NASA EarthData (`https://search.earthdata.nasa.gov`, dataset SRTMGL1) — **requires a free EarthData login**, so `fetch.sh` cannot download these automatically; download the two tiles, gunzip, and place the `.hgt` here. |

`make_cayambe_ic.py` reads the DEM dir via `$DEORBIT_DEM_DIR`, else `data/dem/`.

Checksums for all four files are in `checksums.sha256`.
